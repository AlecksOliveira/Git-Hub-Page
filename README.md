# Git-Hub-Page
É um serviço gratuito do GitHub que publica sites direto de um repositório. Você coloca arquivos HTML, CSS e JavaScript no repositório, e o GitHub gera um endereço público (usuario.github.io/repositorio) onde qualquer pessoa pode abrir a página no navegador.

Para que serve?
Para publicar portfólios, páginas de projetos, documentação e sites simples sem pagar hospedagem nem configurar servidor. Cada vez que você envia uma alteração com git push, o site é atualizado sozinho.

Limitação: serve apenas sites estáticos. Não roda código de servidor nem banco de dados.

Neste projeto: o GitHub Pages publica o portfólio com meus trabalhos acadêmicos, e os PDFs e imagens abrem direto pelo site.
